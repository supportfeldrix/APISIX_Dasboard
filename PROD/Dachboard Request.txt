Custom Apache APISIX Dashboard – Project Description & Requirements
Background
I am currently running Apache APISIX version 3.1.14 on OpenShift and using the built‑in APISIX Dashboard. While functional, the default dashboard is not user‑friendly and does not meet the needs of our Business and DevOps users, who require a simpler, more controlled interface to view and manage APISIX configurations.
To address this, I would like to design and build a custom APISIX dashboard that interacts directly with the APISIX Admin API via REST calls, providing a secure and intuitive management experience.

Objective
Create a custom APISIX management dashboard that:

Is easy to use for Business and DevOps users
Supports role‑based access (view vs admin)
Can be run locally first, then deployed into OpenShift
Integrates with LDAP for authentication and authorization
Uses REST APIs only (no direct etcd access)
Also have a dashboard tab to view memory and cpu usage on the pods listed in openshift via the prometheus metrics setup api
